# Number Guessing Game 🎯

My first C++ project.

## Features
- 3 difficulty levels
- Random number generation
- Limited attempts
- Guess counter
- Too high / too low hints
- Input validation
- Replay system

## Difficulty
- Easy: 1–50, 15 attempts
- Medium: 1–100, 10 attempts
- Hard: 1–500, 7 attempts

## Concepts Learned
- Variables
- Loops
- Conditional statements
- Functions from libraries
- Random number generation
- Input validation
- `cin.fail()`
- `rand()` and `srand()`
- Basic program state management
